# Research

One folder per guide, e.g. `research/03-cons-and-cults/`:

- `brief.md`: scope, target performances, the "room"
- `inventory.jsonl`: one concept per line (concept, category, definition, sources[], tier MUST/SHOULD/AWARE, new_2024_26, note)
- `sources.md`: every source with URL and date checked
- worker outputs as markdown or JSON, each claim with a source

The Oct 2026 research for No. 00, 01, 02 and 05 was not preserved as files; its content and sources live inside the guides.
